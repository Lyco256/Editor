# 003 — canonical vector rules

Canonical vectors are supplied by the requirement cycle, not generated by Setup Codex.

Each navigation vector has: `case_id`, `variant_id`, `document`, `tab_width`, `initial_char_offset`, ordered `operations`, and ordered checkpoints. Every checkpoint has `after_operation`, `char_offset`, `logical_line`, `logical_character`, `display_column`, and `preferred_display_column`.

Conventions: lines/characters/display columns are zero-based; offsets are insertion offsets; EOL is before the line-ending character; EOF equals text length; tab advance is `tab_width - (column % tab_width)`.

Rust tests may not restate numeric expected values from the vector.

Future deterministic acceptance cases must be authored the same way: data first, then checker, then adapter. Natural-language-to-test generation of fixtures/expected values is prohibited.
